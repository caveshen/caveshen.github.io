# The site's domain language

The site is a videogame's menus over Cape Town: a title screen, a
promenade with a character to talk to, and the CV as a character record.

## Language

**Title screen** (also: threshold cover):
The first view: the owner's night photograph under the main menu with
its numbered hotkeys.
_Avoid_: splash screen, landing overlay, hero banner

**Main menu**:
The cover's menu column, and the button on the promenade that brings
the cover back.
_Avoid_: nav, return button, home

**Un-develop**:
The sequence New Game plays: the menu fades, the photograph drains
away, the scene stands as gold line-art for a beat, then the fills
bloom in by depth.
_Avoid_: intro animation, transition effect

**The promenade** (also: the world, the scene):
The vector Cape Town the visitor arrives in, with the Badger on the
rail.
_Avoid_: landing page, home page, canvas

**Area title**:
The region name that plays once on arrival in the promenade.
_Avoid_: heading, banner, toast

**Quest marker**:
The gold diamond bobbing over a character who can be talked to. Gone
while the dialogue is open.
_Avoid_: pin, indicator, icon

**Approach prompt** (also: interact prompt):
The E-keyed prompt that drifts into view over the character on hover or
focus. Activating it starts the dialogue.
_Avoid_: approach button, chip, tooltip, hint

**Dialogue**:
The subtitle and the wheel, floated over the pushed-in scene on a soft
dark ground. Leave with Esc.
_Avoid_: card, modal, plaque, dialog box

**Wheel**:
The ring of options around a gold hub, each on its own spoke with a
numbered cap. A stack on narrow screens.
_Avoid_: menu, list, choices panel

**System option**:
An option in holo blue that leaves the dialogue for another page.
_Avoid_: link, meta option, exit

**Stage voice**:
The narrator's register: italic, murmured stage directions.
_Avoid_: caption style, hint text

**HUD**:
Every control that belongs to the system rather than the world: the
theme toggle, fullscreen, Main menu, the prompt, the area title, the
dialogue. The HUD holds the night register in both themes.
_Avoid_: chrome, UI layer, overlay

**The record** (also: character sheet):
The CV as a character menu: identity, attributes, the skill tree, the
quest log, the codex.
_Avoid_: resume page, about page

**Companion seat**:
The Badger's place beside the record at wide widths, reached by the
view-transition morph from the promenade.
_Avoid_: sidebar, portrait column

**Film grain**:
The full-frame speckle overlay over the promenade at low, constant
opacity. Persistent scene material, not an intro effect.
_Avoid_: noise texture, static filter

**Sea shimmer**:
The horizontal-only displacement that moves the sea and wave fills.
Persistent scene material, not an intro effect.
_Avoid_: water animation, wave loop

**The mark**:
The gold diamond on navy: the favicon, the quest marker, the wheel's
hub, the level badge.
_Avoid_: logo, badger head, icon art
